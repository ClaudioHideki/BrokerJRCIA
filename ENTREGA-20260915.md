O [plano mestre v2](PLANO-MESTRE-JRC-BROKER-v2.md) registra o que está pronto, o que falta e a sequência proposta. O [relatório de validação](VALIDACAO-20260915.md) registra os testes executados.

## Abrir a prévia visual

No diretório do projeto, com Node.js 24.19.0:

```powershell
npm ci
npm run dev:web
```

Abra [a demonstração local](http://127.0.0.1:4317/dashboard?demo=1).

- Na cópia de trabalho entregue nesta máquina, as dependências já estão instaladas e a prévia foi iniciada na porta 4317. Não inicie outra instância enquanto essa porta estiver ocupada.
- Os números da demonstração são sintéticos. A faixa superior identifica esse modo, que bloqueia alterações e não envia mensagens.
- Esse modo só existe no Vite de desenvolvimento; o build de produção não contém o cliente de demonstração.
- Os links internos mantêm o cliente em memória. Para reiniciar a demonstração após atualizar uma página interna, reabra a URL acima com `?demo=1`.

## Operação com a API

Sem `?demo=1`, a interface usa a autenticação e a API reais. Para isso, prepare banco, migrações, Redis, workers, segredos e provedores conforme os guias existentes em `docs/operations/`. O Vite encaminha `/v1` para `http://127.0.0.1:3000`, ajustável por `JRC_API_PROXY_TARGET`. Não coloque segredos em variáveis `VITE_*`.

```powershell
npm run build
npm run typecheck
npm test -- --maxWorkers=2
```

O ZIP é um pacote de fontes: não contém dependências, builds, cache, histórico Git ou estado de autenticação. `npm ci` exige acesso ao registro de pacotes. Os comandos de build e testes foram executados na cópia de trabalho; uma instalação limpa a partir da rede não foi executada nesta sessão.

## Decisão de arquitetura

Priorizar a mensageria canônica para Evolution/Baileys, mantendo Meta Cloud direta. Concluir Typebot sobre esses canais; acrescentar WAHA e Twilio por adaptadores quando o contrato comum estiver pronto. Ligo orienta a experiência de bots, atendimento e relatórios. A fundamentação e as fontes oficiais estão no plano v2.

O provisionamento desta entrega cria até 100 nomes de conexão usando uma conta existente. Não pareia números nem configura automaticamente departamentos, filas, templates ou webhooks. Resultados incertos interrompem o lote; novas etapas exigem reconciliação. O fechamento da tela interrompe próximos envios, mas não desfaz uma requisição já em andamento.
