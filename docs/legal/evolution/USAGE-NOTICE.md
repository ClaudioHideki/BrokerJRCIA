# Aviso de utilização da Evolution API

Texto obrigatório para a área `Configurações → Sobre` do painel administrativo:

> O JRC WhatsApp Broker utiliza componentes de software da Evolution API, conforme as respectivas licenças e atribuições.

Esse aviso deve permanecer claramente visível aos administradores e acessível pela documentação ou pelas configurações do produto. Ele não deve aparecer como endosso, parceria ou propriedade da Evolution Foundation sobre o produto JRC.
