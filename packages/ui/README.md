# @jrc/ui

Tokens visuais reutilizáveis da Console JRC, sem regras de negócio. `jrcTokens` concentra cores de marca e semânticas, tipografia, espaçamento, raios, bordas, sombras e estados. `jrcCssVariables` fornece o mesmo contrato como propriedades customizadas para aplicações web, sem duplicação local dos valores.
